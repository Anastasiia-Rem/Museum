# NAMU Museum Landing Page

A responsive landing page for the National Art Museum of Ukraine (NAMU), built according to the provided Figma design.

The website presents current museum events, exhibitions, a gallery, museum information, and a newsletter subscription form. It is fully responsive and adapted for mobile, tablet, and desktop screens.

## Live Demo

[View the live website](https://anastasiia-rem.github.io/Museum/)

## Technologies Used

- HTML5
- SCSS
- BEM methodology
- JavaScript
- Responsive Web Design
- CSS Grid
- Flexbox

## Features

- Responsive layout for mobile, tablet, and desktop
- Hamburger navigation menu
- Smooth scrolling between page sections
- Current exhibitions and events section
- Responsive image gallery
- Interactive gallery slider
- Newsletter subscription form with validation
- Hover effects and animations
- Interactive social media and contact links

## Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/Anastasiia-Rem/Museum.git
   ```

2. Go to the project directory:

   ```bash
   cd Museum
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```
